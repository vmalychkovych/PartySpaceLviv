PartySpaceLviv — Telegram Bot
Це Telegram-бот, розроблений спеціально для проекту Party Space у Львові. Бот призначений для автоматизації взаємодії з користувачами та управління функціоналом простору через месенджер.
🛠 Технологічний стек
• Мова програмування: Python (100.0%).
• Архітектура: Модульна структура для зручного масштабування.
📁 Структура проекту
Згідно з вихідним кодом, проект має таку організацію файлів:
• main.py — головний файл для запуску бота.
• handlers/ — директорія, що містить логіку обробки вхідних повідомлень та команд.
• keyboards/ — опис інтерактивних кнопок та меню користувача.
• models/ — описи моделей даних.
• services/ — допоміжні сервіси та бізнес-логіка бота.
• data/ — папка для зберігання статичних або динамічних даних проекту.
• .env — файл для конфігурації змінних середовища (наприклад, токен бота).
• .idea/ — налаштування середовища розробки (JetBrains IDE).
